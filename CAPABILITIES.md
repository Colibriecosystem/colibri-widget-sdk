# Среда виджета: что работает, что нет, и как выбрать архитектуру

> English version — [CAPABILITIES.en.md](CAPABILITIES.en.md).

Эта страница — граница возможного. Прочтите её **до** того, как проектировать виджет: половина
вопросов «а почему у меня не работает…» — это не баг, а правило платформы, и здесь написано, какое
и почему.

## Среда: Chromium, и только Chromium

Виджет — это веб-страница в WebView2 (движок Chromium, тот же, что в Microsoft Edge, обновляется
вместе с ним). Из этого следует и хорошее, и жёсткое:

- **Пишите на чём угодно, что собирается в веб.** Современный JS/TS без транспиляции под старые
  браузеры, любые фреймворки, **WebAssembly без ограничений** — Rust, Go, C#, ядро на
  Python через Pyodide. Платформа не различает «чистый JS» и WASM.
- **Ничего, кроме веб-контента, не исполняется.** Бандл — это статические файлы. Терминал никогда
  не запустит из него процесс, не загрузит нативную библиотеку, не вызовет интерпретатор. `.py`,
  `.exe`, `.dll` в бандле — просто байты.
- **Среда одна на всех, origin — у каждого свой.** Ваш bundled-виджет живёт на
  `https://<id>.widgets.colibri.internal`; другой виджет не может даже разрешить ваш origin, ваше
  хранилище и куки недоступны никому, кроме вас.
- **Windows 11 — WebView2 предустановлен.** На чистых Windows 10 / LTSC / Server его может не
  быть: терминал тогда показывает карточку с ссылкой на установку рантайма (~2 МБ, без прав
  администратора) — вашему коду ничего делать не нужно, но знайте, что такой первый экран
  существует.
- **Скрытый виджет не замораживается.** Переключение вкладки не останавливает ваши таймеры и
  сокеты — это осознанное свойство платформы. Обратная сторона — экономить ресурсы должны вы:
  подпишитесь на событие `visibility` и сбавляйте частоту обновлений, когда вас не видно.

## Жёсткие границы

Это не настройки — это конструкция. Ни одно разрешение в манифесте их не снимает.

| Граница | Что именно | Почему |
| --- | --- | --- |
| Сеть — только объявленная | Запрос со страницы уходит только на ваш origin и хосты из `egress`; всё прочее отклоняется. Объявляйте КАЖДЫЙ хост, включая WebSocket-хосты бирж | Пользователь при установке видит, куда виджет может отправлять данные. Список — это обещание, и терминал его исполняет |
| `127.0.0.1` недостижим | Loopback и IP-литералы нельзя вписать в `egress`, и страница до них не достаёт. Это касается и Local API самого терминала, и любой локальной программы | Local API — дверь для нативных программ с другой моделью доверия; виджету он не нужен — мост `window.colibri` умеет больше и без порта с токеном. Канал к «своему локальному бэкенду» см. в разделе про архитектуру |
| Нет файлов и процессов | Никакого доступа к файловой системе, ОС, другим процессам. Хранилище — `colibri.storage`, 5 МБ ключ-значение на виджет | Виджет должен быть безопасен настолько, насколько заявляет консент — а консент не может честно описать «доступ ко всему компьютеру» |
| Ничего не работает при закрытом терминале | Виджет живёт, пока живёт терминал. Фоновых служб нет | Виджет — часть терминала, не отдельная программа |
| Лимиты | 300 вызовов моста в минуту на виджет; свой лимит у `colibri.net.fetch`; торговые бюджеты на подключение (по умолчанию $250 на ордер, 12 ордеров в минуту — пользователь может снять) | Ошибка в цикле не должна стоить пользователю денег или процессора |
| Бандл ограничен | 2000 файлов / 20 МБ на файл / 50 МБ всего | Хеш бандла проверяется при каждом запуске — размер должен оставаться проверяемым |

И одна граница наоборот — в вашу пользу: **токен и порт Local API никогда не появляются в коде
страницы**. Идентичность виджета структурная (терминал знает, какой WebView говорит), поэтому
утечь секрету из вашего кода просто неоткуда.

## Как выбрать архитектуру

Четыре шаблона. Определитесь до первой строчки кода — переезд между ними стоит дороже всего
остального.

### 1 · Всё в странице (bundled)

Данные — свои WebSocket'ы бирж + `colibri.net.fetch` (см. README, раздел про рыночные данные);
терминальные вещи — мост; вычисления — JS или WASM. Так устроены оба эталонных виджета в
`examples/`.

**Берите этот шаблон по умолчанию.** Он единственный даёт полный набор: каталог Nest, консент,
отзыв прав, зафиксированный хеш, тему, установку в один клик — и ни одной зависимости, которую
пользователь ставит отдельно.

### 2 · Hosted: страница с вашего сервера

`entry` — ваш https-URL; бэкенд — ваш сервер, на нём хоть Python, хоть что. Честная цена:
идентичность — origin, а не хеш (янтарная метка `hosted`), и пользовательские данные ходят через
ваш сервер — консент это показывает. Подходит SaaS-инструментам, у которых сервер уже есть.

### 3 · Нативная программа + Local API (вообще без виджета)

Локальная программа на любом языке ходит в терминал по Local API (файл обнаружения
`%APPDATA%\Colibri\localapi.json`; для Python есть официальный SDK —
[colibri-sdk](https://github.com/Colibriecosystem/colibri-sdk)). Открывать монеты, ставить
алерты, читать счета, торговать с грантом — всё это доступно и так, без WebView вообще.
Цена: вашего интерфейса нет внутри терминала, нет каталога Nest, и пользователь доверяет вашему
exe целиком — платформа тут ничего не проверяет и не отзывает.

### 4 · Страница-виджет + локальный бэкенд — пока не поддерживается

Соблазнительная комбинация «интерфейс в терминале, вычисления в моей локальной программе»
упирается в границу `127.0.0.1`: канал страница→локальный процесс сегодня закрыт, и объявить его
в манифесте нельзя. **Санкционированный механизм для этого класса инструментов обсуждается** —
решение будет объявлено здесь и в changelog.

Если ваш инструмент именно такой: соберите весь доступ к данным в один транспортный модуль
(чтобы смена канала не трогала остальной код), стройте интерфейс по шаблону 3 (своя страница в
браузере — она переедет в виджет почти без правок) — и напишите нам: живые примеры двигают
решение быстрее абстрактных.

## Правила хорошего виджета

- **Один транспортный модуль.** Весь `fetch`/`stream`/мост — в одном файле; таблицы, формы и
  графики не знают, откуда берутся данные. Это правило уже дважды окупилось в реальных переездах.
- **Тема — токенами.** Цвета только через `--colibri-role-*` (см. README, «Оформление») — виджет
  следует теме пользователя без единой строчки кода.
- **Подписка вместо опроса.** `colibri.stream.subscribe` вместо цикла с `request` — лимит
  300 вызовов/мин съедается опросом мгновенно, а подписка не тратит его вовсе.
- **`handshake()` — один раз при старте**; права проверяйте по `grantedScopes` и слушайте событие
  `grants` — пользователь может отозвать право на лету, ваш интерфейс должен это пережить.
- **Просите минимум прав.** Каждая строка консента — причина не установить ваш виджет; политика
  каталога прямо называет лишние права поводом для отказа ([policies/CONTENT.md](policies/CONTENT.md)).
