# Виджет для Colibri — стартовый проект

TypeScript + React + Vite. React здесь — пример, а не требование: терминал видит только папку с
`widget.json` и HTML, так что подойдёт что угодно, вплоть до одного статического файла.

> English walkthrough — [README.en.md](README.en.md).

## От нуля до живых данных

```bash
npm install
npm run build
```

Дальше в терминале: **Настройки → Виджеты → «Разработка» → «Загрузить распакованный…»** и выберите
папку **`dist/`** (именно её, не корень проекта). Терминал спросит разрешения — это те, что
объявлены в `public/widget.json`. Согласитесь, и виджет готов: нажмите 🧩 на пустой панели и
выберите его.

На экране — лучшие бид и аск по BTCUSDT, живые.

## Цикл разработки

```bash
npm run watch
```

`vite build --watch` переписывает `dist/` на каждое сохранение, терминал это замечает и
перезагружает виджет — обычно заметно быстрее секунды. Правьте `src/App.tsx` и смотрите.

Кнопка `DevTools` в строке виджета открывает Chromium DevTools по вашей странице.

### Вариант с HMR

Если привычнее горячая замена модулей:

```bash
npm run dev            # vite на localhost:5173
```

и загрузите папку **`dev/`** вместо `dist/` — в её манифесте `entry` указывает на dev-сервер, и
терминал откроет его напрямую. Такая форма работает только для распакованного виджета; упаковать
её нельзя, распространять там нечего.

## Что где лежит

| Путь | Что это |
|---|---|
| `public/widget.json` | манифест собранного виджета; Vite копирует `public/` в `dist/` |
| `dev/widget.json` | тот же манифест, но `entry` — dev-сервер (папку загружают целиком) |
| `src/App.tsx` | сам виджет |
| `src/lib/colibri.js` | SDK, лежит рядом со сборкой (см. `src/lib/README.md`) |

`vite.config.ts` задаёт `base: "./"` — это единственная настройка, которая терминалу важна:
собранный виджет отдаётся из своей папки, поэтому пути к ассетам должны быть относительными.

## Дальше

- Рыночные данные для скринера виджет берёт **сам**, у биржи: маршруты `markets.*` отдают то, что
  открыто у терминала, и по устройству не отвечают на скан всей площадки. Хосты перечисляются в
  `egress` манифеста.
- Когда виджет готов: **«Упаковать для «Гнезда»»** в его строке — получится `.zip` и хеш, которым
  закрепляется листинг.
