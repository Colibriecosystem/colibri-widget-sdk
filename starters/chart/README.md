# Виджет для Colibri — график

Свечи из живых сделок на `<canvas>`: таймфреймы 1s, 5s, 15s и 1m, объём, линии бида и аска,
перекрестие со значениями свечи. Без сторонних библиотек и без сборки.

> English — [README.en.md](README.en.md).

## Откуда этот проект

Его создаёт терминал: **Nest → «Автор» → виджет → «Код» → «Из шаблона» → «График»**. Терминал
вписывает ID виджета в `widget/widget.json` и загружает папку **`widget/`** с горячей
перезагрузкой.

## Как он устроен

| Путь | Что это |
|---|---|
| `widget/index.html` | страница: что показывать и откуда брать данные |
| `widget/chart.js` | рисование: свечи, оси, перекрестие |
| `widget/colibri.js`, `colibri.d.ts` | SDK и его типы — копия `sdk/` этого репозитория |

- Сделки приходят из потока `trades` и копятся посекундными свечами; длинные таймфреймы собираются
  из них при отрисовке. Хранится последний час.
- У виджетов нет маршрута истории свечей, поэтому график начинается с момента открытия. Историю
  берите у биржи сами: добавьте её хост в `egress` манифеста и запросите свечи через
  `colibri.net.fetch` — терминал выполнит запрос за виджет.
- Цвета холст берёт из переменных темы терминала и перечитывает их по событию `theme`.
- Скрытый виджет продолжает собирать сделки, но не рисует, пока его не покажут (событие
  `visibility`).
