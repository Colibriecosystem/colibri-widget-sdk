# Виджет для Colibri — TypeScript + React

Vite, TypeScript и React с типами API. React здесь — пример, а не требование: терминал видит
только папку с `widget.json` и HTML.

> English — [README.en.md](README.en.md).

## Откуда этот проект

Обычно его создаёт терминал: **Nest → «Автор» → виджет → «Код» → «Из шаблона» → «TypeScript +
React»**. Терминал вписывает ID виджета в `public/widget.json`, `dev/widget.json`, `dist/widget.json`
и `package.json` и загружает готовую сборку **`dist/`** с горячей перезагрузкой — виджет работает
сразу, на экране лучшие бид и аск по BTCUSDT.

Взяли папку с GitHub руками? Впишите ID своего виджета в `public/widget.json` и `dev/widget.json`,
выполните `npm install` и `npm run build` и свяжите папку `dist/` через «Код → Папка с проектом».

## Править код

Нужен Node.js 20 или новее. В папке проекта:

```bash
npm install
npm run watch
```

`vite build --watch` переписывает `dist/` на каждое сохранение, терминал это замечает и
перезагружает виджет — обычно быстрее секунды. Правьте `src/App.tsx`. Сборка Vite типы не
проверяет: для этого `npm run typecheck`.

Кнопка DevTools на странице виджета открывает Chromium DevTools по вашей странице.

### Вариант с HMR

```bash
npm run dev            # Vite на localhost:5173
```

и свяжите папку **`dev/`** вместо `dist/`: её `entry` указывает на dev-сервер. Такую форму нельзя
выпустить версией — распространять там нечего.

## Что где лежит

| Путь | Что это |
|---|---|
| `public/widget.json` | манифест; Vite копирует `public/` в `dist/` |
| `dev/widget.json` | тот же манифест, `entry` — dev-сервер |
| `src/App.tsx` | сам виджет |
| `src/lib/colibri.js`, `colibri.d.ts` | SDK и его типы — копия `sdk/` этого репозитория |

`vite.config.ts` задаёт `base: "./"` — единственная настройка, которая важна терминалу: собранный
виджет отдаётся из своей папки, поэтому пути к ассетам должны быть относительными.

## Выпуск версии

«Выпустить версию» на вкладке «Автор» пакует связанную папку `dist/`. Новый номер терминал впишет
и в `dist/widget.json`, и в `public/` и `dev/widget.json`, чтобы следующая сборка его не потеряла.
