# Виджет для Colibri — простой

Одна HTML-страница, без сборки и без Node.js: выбор биржи и монеты, живые бид, аск и последняя
сделка. Выбор сохраняется в `storage` и переживает перезапуск.

> English — [README.en.md](README.en.md).

## Откуда этот проект

Его создаёт терминал: **Nest → «Автор» → виджет → «Код» → «Из шаблона» → «Простой»**. Терминал
вписывает ID виджета в `widget/widget.json` и загружает папку **`widget/`** с горячей
перезагрузкой. Взяли папку с GitHub руками — впишите ID сами и свяжите `widget/` через «Код →
Папка с проектом».

## Править код

Весь виджет — `widget/index.html`. Сохраните файл, и терминал перезагрузит виджет. Типы API лежат
рядом, в `widget/colibri.d.ts`: VS Code подсказывает по ним и в обычном JavaScript.

| Путь | Что это |
|---|---|
| `widget/index.html` | сам виджет |
| `widget/widget.json` | манифест: ID, версия, разрешения |
| `widget/colibri.js`, `colibri.d.ts` | SDK и его типы — копия `sdk/` этого репозитория |

Терминал загружает только `widget/`: README и `.git` в корне проекта виджету не мешают.
