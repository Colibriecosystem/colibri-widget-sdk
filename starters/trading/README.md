# Виджет для Colibri — торговый

Счёт подключения вживую — балансы, позиции, заявки — и **лимитная** заявка, которая уходит только
после явного подтверждения. Vite, TypeScript и React.

> English — [README.en.md](README.en.md).

## Откуда этот проект

Его создаёт терминал: **Nest → «Автор» → виджет → «Код» → «Из шаблона» → «Торговый»**. Терминал
вписывает ID виджета во все `widget.json` и `package.json` и загружает готовую сборку **`dist/`** с
горячей перезагрузкой.

Чтобы виджет мог торговать, нужны два разрешения: `trading` и торговля на конкретном подключении —
её пользователь разрешает именно этому виджету при установке, в «Торговых подключениях», с лимитами
на ордер и на минуту. Настройка Local API для внешних программ к виджетам отношения не имеет. Без
разрешения подключения терминал отвечает `403 trading_not_enabled`, и виджет говорит, где его дать.

## Правила, которые держит этот шаблон

Держите их и в своём виджете:

- **Заявка уходит из одного места** — обработчика кнопки «Подтвердить» (`place` в `src/App.tsx`).
  Никогда при открытии, по таймеру, из обработчика потока, из сохранённых настроек или по клавише.
- **Цена и объём начинаются пустыми** и не восстанавливаются из `storage`: перезапущенный виджет не
  может оказаться в одном клике от заявки, которую пользователь не набирал.
- **Подтверждение закрывается при любой правке**: подтверждают ровно то, что уйдёт.
- **Сначала демо-подключение.** У живого — красная полоса «LIVE — реальные деньги».
- **Только лимитные заявки.** Рыночных заявок, «снять все» и «закрыть всё» в шаблоне нет: это
  массовые действия, и примеру, который копируют, они не нужны. В SDK они есть —
  `trading.cancelAll` и `trading.closePositions`.

Ответ `202` значит «заявка поставлена в очередь», а не «исполнена»: ответ биржи приходит в поток
`orders`. Поверх правил виджета терминал применяет к его заявкам те же лимиты, что и к клику в
стакане.

## Править код

Нужен Node.js 20 или новее:

```bash
npm install
npm run watch
```

Сборка попадает в `dist/`, терминал перезагружает виджет. `npm run typecheck` проверяет типы.
Вариант с HMR — `npm run dev` (порт 5174) и папка `dev/` вместо `dist/`.

| Путь | Что это |
|---|---|
| `src/App.tsx` | виджет: подключение, стакан, заявка, счёт |
| `src/i18n.ts` | тексты на русском и английском |
| `src/styles.css` | стили на переменных темы терминала |
| `public/widget.json`, `dev/widget.json` | манифест и его dev-вариант |
| `src/lib/colibri.js`, `colibri.d.ts` | SDK и его типы — копия `sdk/` этого репозитория |
