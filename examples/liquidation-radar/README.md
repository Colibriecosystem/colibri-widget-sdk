# Радар ликвидаций

Лента ликвидаций по пяти биржам в одной таблице: корзины по размеру за 5 минут, звук на крупных
принтах, цвета — терминальные (янтарный = ликвидировали лонг, голубой = шорт).

Это референсный виджет: он построен только на публичном SDK и на задекларированных доменах, без
каких-либо приватных хуков. Всё, что он умеет, умеет и ваш виджет.

## Что он показывает

- **Данные — собственные WebSocket-подключения виджета.** Терминал не отдаёт ликвидации через
  Local API (в его `trades` их нет по устройству), поэтому виджет ходит на биржи сам — через
  домены из `egress`, которые пользователь видит при выдаче разрешений.
- **Пять бирж, шесть сокетов.** У OKX, Bitget, Gate и Binance есть общебиржевые потоки: одна
  подписка покрывает весь рынок. У Bybit такого потока нет — нужен список инструментов и подписка
  на каждый символ, 843 штуки помещаются в один сокет пачками по 50.
- **Звук и алерты — через уведомления терминала**, поэтому они работают, когда вкладка скрыта:
  скрытые виджеты продолжают работать на полной частоте.

## Запуск

Проще всего — установить виджет из каталога Nest: он там опубликован. Свою сборку можно поставить локально: упакуйте содержимое папки `examples/liquidation-radar/dist` в zip (в корне архива — `widget.json`) и откройте **Nest → «Мои виджеты» → «Добавить локальный виджет…» → «Установить из zip…»**. При установке терминал покажет домены, куда виджет сможет обращаться.

Если хотите поменять код:

```bash
npm install
npm run build
```

Для горячей перезагрузки — `npm run dev` и папка `dev` (в её манифесте `entry` указывает на `http://localhost:5173`). ID `liquidation-radar` занят опубликованным примером, поэтому впишите в `dev/widget.json` свой ID, затем на вкладке «Автор» нажмите «Новый виджет» → «Взять из папки…» и выберите папку `dev`.

## На что смотреть в коде

| Файл | Зачем читать |
|---|---|
| `src/venues/index.ts` | Пять адаптеров. Главное здесь — **какая сторона ликвидирована**: Binance и OKX сообщают сторону ФОРСИРОВАННОГО ОРДЕРА, а Bybit, Bitget и поле `posSide` у OKX — сторону ПОЗИЦИИ. Перепутать их значит инвертировать все цвета на экране, и заметить это без биржевого UI рядом невозможно. |
| `src/venues/types.ts` | `resilientSocket` — переподключение с джиттером и **прикладной** heartbeat: браузер не умеет отправлять WebSocket-пинги, поэтому каждой бирже, которая их ждёт, шлём свой кадр. |
| `src/App.tsx` | Различие между «подключено» и «идут данные». Сокет может завершить handshake, принять все подписки и молчать — это измерено на живой машине, поэтому у каждой биржи отдельный статус. |

## Размеры

Каждая биржа считает объём по-своему, и адаптер приводит всё к базовой монете:
OKX отдаёт КОНТРАКТЫ (нужен `ctVal`), Gate — знаковый контрактный размер (`quanto_multiplier`,
а знак — это и есть сторона), Bitget — сразу котируемый объём (делим на цену), Binance и Bybit —
базовую монету как есть.
