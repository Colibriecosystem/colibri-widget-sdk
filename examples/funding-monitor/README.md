# Фандинг-монитор

> English version — [README.en.md](README.en.md).

Фандинг по шести биржам в одной таблице, отсортированный по годовой ставке, с обратным отсчётом до
расчёта и алертами по порогу.

Это референсный виджет: только публичный SDK и задекларированные домены, никаких приватных хуков.

## Зачем здесь `colibri.net.fetch`

Две из шести бирж — **KuCoin и Kraken Futures — не отдают CORS-заголовки вообще** (проверено
живьём). Обычный `fetch` из страницы их прочитать не может, и обойти это со стороны страницы
нельзя. Поэтому запрос выполняет ТЕРМИНАЛ — по тем самым доменам, которые пользователь видел при
выдаче разрешений. Это же делает список `egress` первым местом на платформе, которое реально
что-то запрещает, а не только показывается при установке.

## Ставки нельзя сравнивать напрямую

Каждая биржа публикует ставку **за свой интервал**: у большинства это 8 часов, у Kraken и
Hyperliquid — час, а у KuCoin интервал разный для разных контрактов (`fundingRateGranularity`
приходит прямо в ответе). Поэтому единственное сопоставимое число — годовая ставка, по ней и
сортировка. Колонка «Интервал» показывает, что именно адаптер использовал.

Отдельно стоит Kraken: его `fundingRate` — **не доля**, а абсолютная величина, её нужно делить на
mark price. Если этого не сделать, ошибки не будет — будет уверенно неправильное число.

## Запуск

Проще всего — поставить виджет из каталога Nest: он там опубликован. Собранная версия лежит и в
репозитории, в папке `dist`, и её можно поставить локально: упакуйте содержимое `dist` в zip
(`widget.json` — в корне архива) и откройте **Nest → «Мои виджеты» → «Добавить локальный виджет…» →
«Установить из zip…»**. При установке терминал покажет домены, к которым виджет сможет обращаться.

Если хотите поменять код:

```bash
npm install
npm run build
```

Для разработки с горячей перезагрузкой — `npm run dev` и папка `dev` (в её манифесте `entry`
указывает на `http://localhost:5173`). ID `funding-monitor` занят опубликованным примером, поэтому
впишите в `dev/widget.json` ID своего виджета (и в `public/widget.json`, если будете собирать свою
версию) и свяжите папку `dev` с этим виджетом на вкладке «Автор» — см.
[«Своя папка»](../../docs/getting-started.md#own-folder).

## На что смотреть в коде

| Файл | Зачем читать |
|---|---|
| `src/venues/index.ts` | Шесть адаптеров, у каждого своя особенность в комментарии: секунды вместо миллисекунд у Gate, абсолютная ставка у Kraken, позиционный zip `universe[i]`/`assetCtxs[i]` у Hyperliquid, POST только у него же. |
| `src/alerts.ts` | Почему алерты защёлкиваются. Ставка держится выше порога часами, а окно расчёта шире периода опроса — без защёлки алерт срабатывал бы на каждом опросе и стал бы бесполезным. |
| `src/App.tsx` | По циклу опроса на биржу, а не один общий: медленная или упавшая биржа не должна задерживать остальные, и каждая держит свои последние хорошие данные, пока повторяет запрос. |

Опрос — раз в минуту с джиттером: шесть запросов в минуту против лимита в 60, так что запас
десятикратный.
