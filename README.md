# SDK виджетов Colibri

> English version — [README.en.md](README.en.md).

Виджет Colibri — веб-страница, которую терминал открывает в панели или в отдельном окне и которой
отдаёт свой API: рыночные данные, счета и заявки пользователя через его подключения, раскладку,
уведомления, ценовые алерты, тему и язык. Пользователь ставит виджеты из каталога Nest и сам
решает, какие разрешения им дать. В этом репозитории — всё, что нужно автору: SDK, четыре шаблона,
из которых терминал создаёт проект, два эталонных виджета, документация и правила публикации.

## <a id="example"></a>Как это выглядит

Стакан: снимок для первой отрисовки, потом живые обновления. `colibri.js` лежит рядом со страницей —
его копия уже есть в каждом шаблоне.

```js
import { handshake, markets, stream } from "./colibri.js";

const exchange = "BinanceSpot";
const symbol = "BTCUSDT";

// Кто я и что мне можно — известно сразу, без await и без события готовности.
const { widgetId, grantedScopes } = handshake();
console.log(widgetId, grantedScopes);

// Снимок, затем живые снимки не чаще 4 раз в секунду. Цены и объёмы приходят строками.
const book = await markets.book(exchange, symbol, { depth: 10 });
console.log(book.bestBid, book.bestAsk);
const stop = stream.subscribe("book", { exchange, symbol, depth: 10, hz: 4 }, (live) => {
  console.log(live.bestBid, live.bestAsk);
});
```

Что здесь может пойти не так и как это пережить — в [рецепте про стакан](docs/recipes.md#order-book).

## <a id="layout"></a>Что где лежит

| Папка | Что в ней |
| --- | --- |
| [`sdk/`](sdk/) | SDK — `colibri.js` и его типы `colibri.d.ts`: два файла, которые кладут рядом со страницей |
| [`starters/`](starters/) | шаблоны; каждый релиз этого репозитория — релиз шаблонов, терминал берёт их оттуда |
| [`examples/`](examples/) | эталонные виджеты: исходники и собранные `dist/` |
| [`docs/`](docs/) | документация автора: первый виджет, справочник, рецепты, публикация |
| [`policies/`](policies/) | правила каталога Nest: что можно публиковать и как виджет снимают |
| [`scripts/`](scripts/) | проверки репозитория: документация, шаблоны, копии SDK |
